Uses RANK() OVER (PARTITION BY category ORDER BY price DESC). pg_ivm cannot handle window functions.
This example uses HAVING and RANK() OVER -- SQL constructs that pg_ivm, Hasura, Debezium, Supabase, and ElectricSQL all fail on. Only pg_reactive delivers live deltas for these queries. When the average price drops below $50 for a category, it disappears from the left panel. Rankings re-sort automatically when prices change.
