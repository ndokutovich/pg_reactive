03 — Per-user Inventory

Each player has their own audience-bound subscription. The query_id (inv_<uuid>) is derived server-side from auth.uid(); the audience predicate {"sub":"<uuid>"} makes another player's JWT unable to open this WebSocket even if they guess the query_id.

Signed in as …

First load auto-signs-up an anonymous guest account. Open this in a second profile / private window — that's a different player with a different inventory.

Inserts are gated by RLS — you can only write rows where player_id = auth.uid().
