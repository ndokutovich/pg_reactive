  DATABASE LAYER (PostgreSQL + C Extension — ext/)
  ┌─────────────────────────────────────────────────────────────────┐
  │  pg_reactive.c  →  pgr.subscribe() / pgr.unsubscribe()         │
  │                    ProcessUtility_hook (DDL auto-unsubscribe)   │

  │                    uint64 column bitmask change tracking        │
  │  recompute.c    →  EXCEPT-based delta via temp table           │
  │                    NOTIFY "pgr" JSON payload                    │
  │                    sequence numbers for gap detection           │
  │  bgworker.c     →  optional async recompute background worker  │
  └─────────────────────────────────────────────────────────────────┘

  NOTIFY WIRE FORMAT (channel: pgr)
  Delta:    {"query_id":"...","inserted":[...],"deleted":[...],"seq":N}
  Overflow: {"type":"overflow","query_id":"...","fetch":true}
  Welcome:  {"type":"subscribed","query_id":"..."}

GUC Parameters (C Extension)
Parameter Type Default Description
pg_reactive.max_subscriptions PGC_POSTMASTER 1024 Shared memory slots for subscriptions. Requires server restart. Set via docker-compose command: flag as -c pg_reactive.max_subscriptions=N.
pg_reactive.async_recompute PGC_POSTMASTER off Enable background worker for async recompute. Requires restart. When disabled, recompute runs in the trigger context (synchronous). When enabled, a bgworker processes the recompute queue.
